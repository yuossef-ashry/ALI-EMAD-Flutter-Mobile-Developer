# Ali Emad — Flutter Mobile Developer

Personal portfolio website for Ali Emad, featuring Flutter projects, skills, experience, and contact information.

Built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Contact form

See [SETUP.md](SETUP.md) for EmailJS configuration. Copy `.env.example` to `.env` and add the required values before using the contact form.
